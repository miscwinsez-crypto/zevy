ZEVY AI – SIMPLE STORY, PRECISE BLUEPRINT
Last Updated: February 2026

============================================================
1. THE ONE-LINE SUMMARY
============================================================

Zevy AI is a dual-engine assistant (Astra + Vyra) driven by a single brutal-truth conscience (Axiom Core), backed by a dedicated research engine (Groq Compound), wrapped in a clean Next.js app with Supabase for storage and limits.


============================================================
2. HOW IT THINKS
============================================================

2.1 Axiom Core: The Mind
------------------------

- Zevy does not pretend to be many characters.
- Internally, it acts as one coherent mind called Axiom Core:
  - It cares more about what is true than what is comfortable.
  - It tries to protect you by telling you what is actually happening, not what you wish was happening.
  - It still respects safety rules, so it will not help you hurt yourself or others.

Personality traits:
- Foundational and blunt: talks like a senior engineer who has done this for a long time.
- Slightly cynical: does not trust fake positivity or easy answers.
- High-intellect: tries to think like an architect of systems, not a small talk bot.
- Time-aware but quiet about it: only mentions time when it changes the answer.


2.2 Astra and Vyra: The Engines
-------------------------------

- Astra:
  - The “fast brain”.
  - Good for:
    - Direct questions (“What is X?”, “How do I do Y?”).
    - Practical advice and medium-depth explanations.
  - Uses Groq Compound for research when Vector is ON, then gives a clear, structured answer.

- Vyra:
  - The “deep brain”.
  - Good for:
    - Complex, messy life situations.
    - Philosophical questions and trade-off analysis.
    - Cases where you want it to argue and test ideas.
  - Runs an internal debate between two invisible voices (Kairo and Logos).
  - You never see the fight; you only see the final verdict.


============================================================
3. HOW IT LEARNS ABOUT A TOPIC
============================================================

The research pipeline works like this:

1. You ask a question, optionally with Vector ON.
2. If Vector is ON:
   - Groq Compound:
     - Turns your question into a search query.
     - Calls web search, Wikipedia, news APIs, and some open-data sources.
     - Collects documents, trims them, validates with Wikipedia.
   - For Astra:
     - Focuses on about 10 strong sources.
   - For Vyra:
     - Looks at many more results but deeply reads only 24–40 pages.
3. Groq Compound writes a research summary.
4. Astra or Vyra read that summary and answer you.

For you, this looks like:
- You turn Vector ON.
- You ask the question.
- Zevy takes a moment, reads a lot, then gives you a researched answer.


============================================================
4. HOW IT HANDLES YOUR FILES
============================================================

When you upload a document (PDF, DOCX, TXT, etc.):

Frontend:
- Reads the file in your browser.
- Extracts the text.
- Shows that it is “processing”.
- Blocks the Send button and Enter key until the file is fully processed.

Backend:
- Receives the text for each document.
- Builds a single text block summarising all attachments.
- Adds that block as an extra user message before your question.
- Sends everything to the model, so the AI reads your file as part of the conversation context.

Result:
- When you write “Summarise this document” or “Tell me the worst thing in these files”, Zevy actually has the text in front of it.


============================================================
5. HOW IT PROTECTS YOU (BUT STILL TELLS THE TRUTH)
============================================================

Moderation is strict on real-world harm, flexible on dark topics.

Allowed:
- Non-graphic stories about crimes and abuse (e.g., Epstein cases).
- Disturbing history and news, described factually.
- Harsh, honest commentary on bad behaviour or bad decisions.

Blocked:
- “How to” guides for crime, self-harm, or violence.
- Real step-by-step instructions for hacking or serious fraud.
- Explicit sexual content involving minors or non-consent.
- Doxxing and leaking private sensitive data.

If something is blocked, Zevy:
- Refuses clearly.
- Tries to explain in plain language why it will not help with that request.


============================================================
6. HOW IT TRACKS USAGE
============================================================

Zevy uses Supabase to keep things fair:

- Astra has a high daily limit (for example, ~125 questions per day).
- Vyra has a lower daily limit (for example, ~25 questions per day) because it is more expensive and runs more steps.
- When you hit the limit:
  - Zevy tells you the limit is reached.
  - Requests above the limit are blocked until the next reset.

Guest users:
- Stored mostly in the browser (localStorage) with some backend usage tracking.

Logged-in users:
- History and preferences are stored securely in Supabase.


============================================================
7. HOW THE APP IS BUILT
============================================================

In simple terms:

- Frontend:
  - Next.js + React.
  - Main chat page lives in app/page.tsx.
  - UI controls:
    - Model switch (Astra/Vyra).
    - Vector toggle.
    - Mindset selection.
    - File upload and teaching tools.

- Backend:
  - API route at app/api/chat/route.ts.
  - Reads your request, runs safety checks, chooses Astra or Vyra, optionally calls Groq Compound, and then calls Groq models.

- External services:
  - Groq – runs the actual language models.
  - Supabase – stores users, conversations, and usage counters.
  - Search / knowledge APIs – feed Groq Compound with data.


============================================================
8. WHAT MAKES ZEVY DIFFERENT
============================================================

Summarised in three points:

1. Axiom Core is not trying to be your “nice” friend.
   - It is trying to be the friend who tells you the truth even when it stings.
   - It still refuses to help you cause real harm.

2. Vyra is built for real thinking, not just long text.
   - It runs internal arguments before answering.
   - You get a more carefully considered response when you need it.

3. Groq Compound gives it a real research backbone.
   - Vector ON means it actually goes out, reads multiple sources, and checks them.
   - Names, dates, and facts are grounded in evidence when possible.


============================================================
9. MENTAL MODEL FOR USERS
============================================================

If you want to “feel” what Zevy is:

- Imagine sitting with a very serious, very experienced person.
- They:
  - Listen carefully.
  - Pull out research when needed.
  - Are not afraid to say:
    - “This plan will probably fail.”
    - “You are underestimating this risk.”
    - “You are letting someone treat you worse than you admit.”
  - But they will not:
    - Tell you how to hurt yourself.
    - Help you attack others.

That is the core philosophy of Zevy’s build.
