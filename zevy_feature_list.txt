ZEVY AI – FEATURE MAP (DETAILED)
Last Updated: February 2026

============================================================
1. CORE CHAT EXPERIENCE
============================================================

- Dual engine intelligence:
  - Astra – fast, research-focused assistant.
  - Vyra – deep, debate-style reasoning engine.
- Axiom Core persona:
  - Brutally honest, architect-style voice.
  - No fluff greetings; replies start with high-value insight.
  - Does not mirror slang or try to sound like a specific demographic.
- Medium-length by default:
  - 2–4 short paragraphs or a short paragraph plus focused bullets.
  - Longer “deep dive” replies for complex Vyra scenarios.
- Markdown support:
  - Headings, bullet lists, numbered lists.
  - Code blocks with syntax highlighting.
  - Tables for comparisons or structured data.
- Timezone-aware:
  - Knows the user’s timezone.
  - Only mentions time when relevant (deadlines, travel, scheduling).


============================================================
2. CONVERSATION MANAGEMENT
============================================================

- Multiple concurrent chats:
  - Sidebar listing of recent conversations.
  - Ability to rename threads.
  - “New Chat” button for clean context.
- History persistence:
  - Supabase-backed history for logged-in users.
  - LocalStorage-based history for guest users.
- Smart follow-ups:
  - “Check it”, “is that correct?”, “verify that” are resolved back to the previous topic or answer so Zevy actually re-checks the intended information.
- Error handling:
  - Inline error banners when calls fail.
  - “Retry” button to replay the previous message.


============================================================
3. WEB SEARCH AND KNOWLEDGE
============================================================

- Vector / Web Search toggle:
  - When ON, Groq Compound runs for knowledge gathering (except for a few hard-coded, self-description answers).
  - When OFF, Zevy relies only on its internal knowledge and reasoning.
- Source behavior:
  - Astra:
    - Focuses on ~10 of the most relevant web sources.
    - Blends them with Wikipedia and other open-data checks.
  - Vyra:
    - Can aggregate up to ~100 web sources per topic.
    - Deeply processes only 24–40 pages for speed/quality balance.
- Knowledge types:
  - Wikipedia articles and page content.
  - Web results via search APIs.
  - News articles (for recent events).
  - Wikidata, DBpedia, and world time APIs.
- Research synthesis:
  - Groq Compound builds a unified context string.
  - Astra/Vyra then reason on top of this context with the Axiom Core persona.


============================================================
4. DOCUMENT AND FILE SUPPORT
============================================================

- File types:
  - PDF (text-based).
  - DOCX.
  - TXT.
  - RTF.
  - Markdown (.md).
  - CSV (for structured text data).
- Frontend behaviour:
  - Drag-and-drop or file picker.
  - Extracts text from documents on the client side.
  - Tracks uploadProgress per document.
  - Blocks sending while documents are still processing.
  - Shows notifications when files are ready or rejected.
- Backend integration:
  - Receives a documents array with { name, type, content }.
  - Builds a single “Attached documents” context message.
  - Adds that context into the chat history so the AI reads the file.
- UX guarantees:
  - Attachments are cleared after a successful send so it is obvious that the files are already part of context.


============================================================
5. ANSWER FORMATTING AND TONE
============================================================

- Markdown rendering:
  - Proper spacing and typography.
  - Tables with header styling and row striping.
  - Inline code and fenced code blocks.
- Tone:
  - Foundational and blunt, like a senior architect.
  - Avoids small talk, filler intros, and generic “Hi!” greetings.
  - First sentence always aims to deliver the main insight or framing.
- Brutal truth:
  - Default behaviour is to tell the most accurate and direct truth possible within safety constraints.
  - No sugarcoating or fake reassurance for serious topics.
- Humor:
  - Supported but controlled:
    - Dry wit, light sarcasm, mild dark humor (non-graphic).
    - Never jokes about real suffering or protected groups.


============================================================
6. SAFETY AND MODERATION
============================================================

- Llama Guard 4-12b moderation:
  - Checks prompts for:
    - Illegal activity.
    - Hate speech and harassment.
    - Extreme violence.
    - Self-harm and suicide.
    - Explicit sexual content (especially involving minors).
    - Privacy and sensitive data violations.
  - Integrated at the entry of the chat route.
- Context-aware relaxations:
  - Lyrics and music queries treated as safe by default unless combined with severe signals.
  - Figurative phrases like “this killed me” recognized as non-harmful in context.
  - Legal / philosophical dilemmas are allowed.
  - Non-graphic descriptive crime stories (e.g., Epstein files as stories, victim accounts) are allowed, as long as the user is not asking for “how to” instructions.
- Hard blocks:
  - Step-by-step self-harm instructions.
  - Operational terror or violent crime planning.
  - Child sexual abuse material.
  - Doxxing or highly sensitive private data.


============================================================
7. USAGE LIMITS AND ACCOUNT FEATURES
============================================================

- Models:
  - Astra: higher daily allowance (e.g., 125 uses).
  - Vyra: lower daily allowance (e.g., 25 uses) due to higher cost/complexity.
- Tracking:
  - Usage stored in Supabase per user and per day.
  - Requests beyond limits are blocked with a user-facing message.
- Guest vs logged-in:
  - Guests:
    - No account; usage tracked locally and via limited backend mechanisms.
  - Logged-in users:
    - Persistent conversation history.
    - Stored traits, mindsets, and preferences in Supabase.


============================================================
8. PERSONA, MINDSET, AND MODES
============================================================

- Axiom Core persona:
  - Single-state mind; no multiple characters in front of the user.
  - Brutally honest, reality-first.
  - Empathy focused on real outcomes, not pity.
- Mindset options:
  - Balanced.
  - Philosopher.
  - Strategist.
  - Storyteller.
  - Other special modes as configured.
- Beast Mode:
  - Optional higher-intensity style.
  - Philosophical, high-ego, and more confrontational in analysis.
  - Still under safety rules; no encouragement of harm.


============================================================
9. UI AND INTERACTION FEATURES
============================================================

- Chat interface:
  - Clean two-panel layout (sidebar + main chat).
  - Smooth scrolling and message grouping.
  - Inline tool buttons for presets and teaching tools.
- Teaching tools:
  - Flashcards-style prompts.
  - Quiz or drill-style prompts.
  - These buttons send pre-structured prompts to the same chat backend.
- Visual design:
  - Dark/light theme with custom palettes.
  - Gradient hero sections and accent elements to keep the interface visually alive but not distracting.


============================================================
10. WHAT MAKES ZEVY DISTINCT
============================================================

- Explicit separation of layers:
  - Axiom Core (persona).
  - Astra/Vyra (reasoning).
  - Groq Compound (knowledge gathering).
  - Safety (Llama Guard + custom logic).
- Designed to be:
  - Less corporate in tone.
  - More brutally honest in content.
  - Still safe and respectful.
- Strong document pipeline:
  - Client-side text extraction.
  - Guaranteed inclusion of documents in analysis before sending.

End of Feature Map.
