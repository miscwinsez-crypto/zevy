ZEVY AI – FEATURE MAP (DETAILED)
Last Updated: March 2026 (v2.0 "Unbreakable" Update)

============================================================
1. CORE CHAT EXPERIENCE
============================================================

- Dual engine intelligence:
  - Astra – fast, research-focused assistant (now more confident on facts).
  - Vyra – deep, debate-style reasoning engine (now more reliable).
- Axiom Core persona:
  - Brutally honest, architect-style voice.
  - No fluff greetings; replies start with high-value insight.
  - Does not mirror slang or try to sound like a specific demographic.
- Medium-length by default:
  - 2–4 short paragraphs or a short paragraph plus focused bullets.
  - Longer “deep dive” replies for complex Vyra scenarios.
- Markdown support:
  - Headings, bullet lists, numbered lists.
  - Code blocks with syntax highlighting.
  - Tables for comparisons or structured data.
- Timezone-aware:
  - Knows the user’s timezone.
  - Only mentions time when relevant (deadlines, travel, scheduling).


============================================================
2. CONVERSATION MANAGEMENT
============================================================

- Multiple concurrent chats:
  - Sidebar listing of recent conversations.
  - Ability to rename threads (Smart truncation: first 8 words or 50 chars).
  - “New Chat” button for clean context.
- History persistence:
  - Supabase-backed history for logged-in users.
  - LocalStorage-based history for guest users.
- Smart follow-ups:
  - “Check it”, “is that correct?”, “verify that” are resolved back to the previous topic or answer.
- Error handling (ENHANCED):
  - Automatic retry logic (up to 2 retries) for transient API failures.
  - Circuit breaker prevents server hangs during outages.
  - Clear, specific error messages for moderation refusals or timeouts.


============================================================
3. WEB SEARCH AND KNOWLEDGE
============================================================

- Vector / Web Search toggle:
  - Persists state across sessions (remembers if you left it ON).
  - When ON, Groq Compound runs for knowledge gathering.
  - When OFF, Zevy relies on internal knowledge (with explicit "I might be wrong" caveats for volatile topics).
- Source behavior:
  - Astra: ~10 primary sources, confident on stable facts (history, science).
  - Vyra: Up to ~100 sources, deep reasoning, "savage" truth-seeking.
- Knowledge types:
  - Wikipedia, Web search, News, Wikidata, DBpedia.
- Research synthesis:
  - Cleaned search queries (removes conversational noise like "Hey Zevy").
  - Sources cited in a structured "Sources:" section at the end of replies.


============================================================
4. DOCUMENT AND FILE SUPPORT (HARDENED)
============================================================

- File types (Text-based only):
  - PDF, DOCX, TXT, RTF, Markdown (.md), CSV.
- Security & Validation:
  - Strict 5MB file size limit per file.
  - Explicit type checking (rejects binaries/images to prevent crashes).
  - Browser-safe text extraction (no crashing on DOCX/PDF).
  - Content sent as plain text (not base64) for perfect AI readability.
- Context Window:
  - Massive 24,000 character limit (approx 10-12 pages) for deep document analysis.
- UX:
  - Clear progress indicators.
  - Warning notifications for unsupported files.


============================================================
5. SECURITY AND MODERATION (NEW v2.0)
============================================================

- Rate Limiting (Hardened):
  - Uses IP Address + User Agent fingerprinting.
  - Blocks brute-force login/signup attacks effectively.
- Prompt Injection Protection:
  - System prompt explicitly forbids revealing internal instructions ("Axiom", "Vyra", system prompt).
  - Refuses attempts to "ignore previous instructions" to leak secrets.
- Llama Guard Integration:
  - Checks for illegal, violent, or self-harm content.
  - Returns clear refusal messages to the user (no silent failures).
- Circuit Breaker:
  - Automatically trips if the AI service fails 5 times in a row.
  - Resets after 1 minute.
  - Prevents cascading failures and server hangs.


============================================================
6. USAGE LIMITS AND ACCOUNT FEATURES
============================================================

- Models:
  - Astra: higher daily allowance.
  - Vyra: lower daily allowance.
- Tracking:
  - Usage stored in Supabase per user/day.
  - Limits enforced strictly.
- Guest vs logged-in:
  - Guests: Limited usage, local history.
  - Logged-in: Cloud history, higher limits, persistent preferences.


============================================================
7. PERSONA, MINDSET, AND MODES
============================================================

- Axiom Core persona:
  - Single-state mind; brutally honest, reality-first.
- Mindset options:
  - Balanced, Philosopher, Strategist, Storyteller.
- Beast Mode:
  - High-intensity, philosophical, confrontational analysis.
- Flashcards & Quiz Mode:
  - Automatically forces "Astra" (Fast) model for instant speed.
  - Prevents timeouts on simple interactive tasks.


============================================================
8. UI AND INTERACTION FEATURES
============================================================

- Chat interface:
  - Clean two-panel layout.
  - Clear model labels: "✦ Astra Fast" / "✧ Vyra Deep".
  - Auto-scroll and smooth message streaming.
- Teaching tools:
  - Flashcards and Quiz buttons (optimized for speed).
- Visual design:
  - Dark/light theme.
  - Responsive mobile design.


============================================================
9. WHAT MAKES ZEVY DISTINCT (v2.0)
============================================================

- "Unbreakable" Reliability:
  - Circuit breakers, auto-retries, and strict validation make it production-ready.
- Deep Context:
  - 24k character document window is significantly larger than standard chatbots.
- Brutal Truth:
  - Unapologetic focus on reality over comfort.
- Separation of Concerns:
  - Distinct layers for Persona, Reasoning, Knowledge, and Safety.

End of Feature Map.
